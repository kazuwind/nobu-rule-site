プライバシーポリシー

制定日：2026年11月23日

1. 対象

このポリシーは、Google Apps Script で動く個人用の道具「Nobu rule」（以下「本アプリ」）に適用されます。本アプリは開発者本人だけが使うもので、一般の方への提供は行っていません。

2. Google ユーザーデータの取り扱い

本アプリは、利用者が許可した次の権限だけを使います。

  • Google スプレッドシート（https://www.googleapis.com/auth/spreadsheets）：本アプリが作成したスプレッドシートに、取得した価格と、利用者が入力した記録（方針、売買の記録、振り返り、メモ）を保存し、読み出します。
  • 外部サービスへの接続（https://www.googleapis.com/auth/script.external_request）：相場データの提供元（Twelve Data）から価格を取得します。
  • トリガーの管理（https://www.googleapis.com/auth/script.scriptapp）：価格を定期的に取得するために使います。

本アプリは、利用者の Google ドライブにあるほかのファイル、メール、連絡先などにはアクセスしません。

3. 保存場所

データはすべて、利用者自身の Google アカウントのスプレッドシートに保存されます。開発者が運営するサーバーやデータベースはありません。

4. 第三者への提供

Google ユーザーデータを第三者に提供・販売・共有することはありません。相場データの提供元へ送るのは、価格の取得の要求（銘柄、時間足、本数）とAPIキーだけで、利用者の Google ユーザーデータは含みません。広告や分析のためのツールは使っていません。

5. Limited Use（Google API サービスのユーザーデータに関するポリシー）

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

Nobu rule's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 削除

利用者は、Google ドライブから本アプリが作成したスプレッドシートを削除することで、保存したデータを消せます。本アプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 変更

このポリシーを変更する場合は、このページを更新します。
